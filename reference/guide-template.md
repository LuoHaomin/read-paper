# 导读模板（guide）

**每篇论文必产出一个 `导读.md`**，放在该论文输出文件夹根目录，与 [README.md](overview-template.md)（导航中枢）并列、互补：

- **README = 地图**：贡献地图、骨架图、互链——回答"有什么、在哪找"。
- **导读 = 导游**：教学叙事——回答"这篇论文是怎么回事"。目标是**让读者 30 分钟读懂核心思路，再回原文时各节都变成填空题**。

写导读的时机：**所有条目写完之后**（导读是对条目的蒸馏，每个想法都要能链到已存在的条目）。README 里"建议阅读顺序"固定把导读列为第 0 步。

## 二、构造要点（anatomy）

| 章节 | 必需？ | 作用 | 常见错误 |
|------|------|------|---------|
| 标题 + 读者定位 | ✅ | 声明读法与时间预算 | 写成论文摘要的复述 |
| §0 问题 | ✅ | 让没读过论文的人知道在对抗什么 | 背景铺太长；难点不具体 |
| 想法 1..N | ✅ | 论文的可蒸馏骨架 | 想法太多（>5 说明没蒸馏好）或太少（1 个等于没拆） |
| 每个想法内的"容易忽略的点" | ✅ | 提前拆掉读者必踩的坑 | 写成条目内容的复制 |
| 想法末尾的"→ 细节"链接 | ✅ | 导读与条目体系焊在一起 | 只链接不写"去看什么" |
| 尾注对比 | 看情况 | 定位贡献（vs 朴素方案/前人） | 替作者编造对比对象 |
| 全文一图流 | ✅ | 一张图复述想法间的咬合 | 画成条目依赖图（那是 README 骨架图的职责） |
| 原文快速阅读路线 | ✅ | 从导读平滑过渡到原文 | 只列章节名不讲为什么 |
| 导读→条目对照表 | ✅ | 双向导航收尾 | 漏掉任何已产出的条目 |

## 三、风格约定（写死，照做）

- **语言：中文为主**（数学符号、专有名词保留原文）；公式规范 LaTeX。
- **大白话优先**：每个想法先说人话再上公式；类比可以用（如"数据自己当 ancilla"），但类比之后必须落在精确陈述上。
- **公式限量**：全文 5–10 个 display 公式封顶——导读卖的是"为什么"，不是"怎么算"。完整推导一律推给条目链接。
- **不重复条目**：导读里的推导不超过 3 行；超过就说明这段该在条目里。
- **防幻觉同样生效**：每个公式/数字挂原文出处（Eq.(N)/(p.X)）；论文没有的对比或局限不编造（写"原文未讨论"）。
- **图**：一图流用 **mermaid**（关系）；若某个想法本质是几何的，可在该想法内配小 SVG（裸写，勿包代码块）。
- **篇幅**：1,500–2,500 字为宜；承重单元 ≤3 的小论文可压到 800 字，但骨架一节不能少。
- **文件名固定 `导读.md`**（数字前缀保证排在条目之前）。

## 四、范例（节选自一次真实运行，质量锚点）

论文：*Symmetry as Workspace: Constant-Depth Universal Certification and Metrological Readout*（置换不变纯态的常数深度认证与计量）。以下节选展示"问题 + 一个想法"写到什么程度算够（原文导读有 4 个想法，这里取前两个之一压缩）。

````markdown
# 导读：三十分钟读懂本文

## 0. 问题：对称态"维度小"但"读出难"

n 个 qubit 的置换不变纯态 |ψ⟩ = Σ c_k|D_k^n⟩ 只活在 n+1 维对称扇区里，但振幅 c_k
**毫无结构**——不是乘积态、没有固定电荷、没有短电路描述。两个看似必须"全局测量"的任务：

1. **认证**：判断实验态对目标的保真度。目标投影是 n 体算符：朴素测法需要深度 ~n 的电路
   （先转 Dicke 基再读出）；用经典影子，对全局秩一投影的样本复杂度指数爆炸。
2. **计量**：若 |ψ_θ⟩ 带参数，常数深度测量能保住多少 QFI？

全文的回答：**两件事都能做，而且用的是同一台、常数深度、与任务无关的随机测量**。

## 想法 1：对称性 = 工作空间（§2，全文的物理起点）

标题 "Symmetry as Workspace" 是字面意思。观察只有一行：

> 全局置换不变 ⇒ **局部也对称**。任取 L 个 qubit 的块 A，约化态 ρ_A 支撑在 Sym^L(C²)，
> 维度 L+1，**与 n 无关**（引理 2.1；证明两行：块内置换是全体置换的子群）。

工程后果：块内对称态只有 q = L+1 个基矢量，一个**固定深度**的块内幺正就能解码
|D_a^L⟩ ↦ |a⟩_in ⊗ |0…0⟩_work——把块信息读进逻辑寄存器，**剩下的 qubit 全部清零变成
干净 workspace**。关键：workspace 不是外部 ancilla，是数据 qubit 自己腾出来的。

两个容易忽略的点：
- 这是**支撑**性质，不是纠缠性质：各逻辑块之间仍可任意纠缠，全文没有 product 假设；
- 常数 q = 2^r、L ≥ 12r 纯粹是容量核算（每块要装下若干逻辑 q-dit），没有物理内容。

→ 细节：[Lemma2.1_decoder.md](Lemma2.1_decoder.md)
````

> 这个范例的密度就是锚点：想法标题带比喻、观察用一句话陈述并给"证明几行"的量级、后果立刻落到操作层面、易错点拆的是真会踩的坑、链接指名道姓。

---

**记住**：导读是**蒸馏**不是**摘要**——摘要按论文结构走，导读按"读者的理解顺序"走。判断一份导读合格的标准：读者读完它，能用自己的话说出"这篇论文靠哪几个想法站起来、各自挡住了哪颗子弹"。
